# 02. Словарь данных

Источник: dunnhumby, The Complete Journey (~2 500 домохозяйств, ~2 года).
Роли: КЛЮЧ (связь таблиц), МЕТРИКА (считаем), ФИЛЬТР (отбираем/группируем), КОНТЕКСТ.
Названия колонок могут отличаться регистром (household_key / HOUSEHOLD_KEY).
Звёздочка * = не проверено по источнику, сверить после скачивания.

## Общие замечания
- day и week_no: номера от начала наблюдения, не календарные даты.
- Скидки в чеках обычно записаны отрицательными числами* (проверить знак).
- Демография есть примерно у трети семей.

---

## transaction_data: покупки (одна строка = одна позиция в чеке)

| Колонка | Тип | Описание | Роль |
|---|---|---|---|
| household_key | int | Идентификатор домохозяйства (по карте лояльности) | КЛЮЧ |
| basket_id | int | Идентификатор чека, т.е. одного похода в магазин. Несколько позиций с одним basket_id = один визит | КЛЮЧ / МЕТРИКА (число визитов) |
| day | int | Номер дня от начала наблюдения | ФИЛЬТР (период до/после) |
| week_no | int | Номер недели от начала наблюдения | ФИЛЬТР (агрегация по неделям) |
| trans_time* | int | Время покупки (формат ЧЧММ) | КОНТЕКСТ |
| product_id | int | Идентификатор товара | КЛЮЧ |
| store_id | int | Идентификатор магазина | ФИЛЬТР |
| quantity* | int | Сколько единиц товара куплено в позиции | МЕТРИКА |
| sales_value* | float | Сумма, которую магазин получил за позицию (после скидок). Не равна цене на полке | МЕТРИКА (траты) |
| retail_disc* | float | Скидка от самой сети (программа лояльности) | МЕТРИКА |
| coupon_disc* | float | Скидка по купону производителя | МЕТРИКА (затраты на купоны) |
| coupon_match_disc* | float | Скидка, которую сеть добавляет, сопоставляя купон производителя | МЕТРИКА (затраты на купоны) |

Цена на полке (по формуле из документации*): (sales_value − (retail_disc + coupon_match_disc)) / quantity.

## campaign_desc: справочник кампаний (30 строк)

| Колонка | Тип | Описание | Роль |
|---|---|---|---|
| campaign | int | Номер кампании (1-30) | КЛЮЧ |
| description | str | Тип кампании: A, B или C | ФИЛЬТР |
| start_day | int | День начала кампании | ФИЛЬТР (граница периода) |
| end_day | int | День окончания кампании (купоны действуют в этом окне) | ФИЛЬТР |

## campaign_table: участие семей в кампаниях

| Колонка | Тип | Описание | Роль |
|---|---|---|---|
| household_key | int | Семья, получившая кампанию | КЛЮЧ |
| campaign | int | Номер кампании | КЛЮЧ |
| description | str | Тип кампании (A/B/C) | ФИЛЬТР |

Одна семья может быть в нескольких кампаниях (проверить).

## coupon: какие купоны относятся к кампаниям

| Колонка | Тип | Описание | Роль |
|---|---|---|---|
| coupon_upc | int | Код купона | КЛЮЧ |
| product_id | int | Товар, на который действует купон (у одного купона может быть много товаров) | КЛЮЧ |
| campaign | int | Кампания, в рамках которой купон разослан | КЛЮЧ |

## coupon_redempt: погашения купонов

| Колонка | Тип | Описание | Роль |
|---|---|---|---|
| household_key | int | Семья, погасившая купон | КЛЮЧ |
| day | int | День погашения | ФИЛЬТР |
| coupon_upc | int | Код погашенного купона | КЛЮЧ |
| campaign | int | Кампания, к которой относится купон | КЛЮЧ |

Не путать: получил кампанию (campaign_table) и погасил купон (coupon_redempt).

## causal_data: товары в рассылке и на витрине (очень большая)

| Колонка | Тип | Описание | Роль |
|---|---|---|---|
| product_id | int | Товар | КЛЮЧ |
| store_id | int | Магазин | КЛЮЧ |
| week_no | int | Неделя | КЛЮЧ |
| display | str | Код размещения товара на витрине в магазине (расшифровка в документации*) | КОНТЕКСТ |
| mailer | str | Код размещения в рекламной рассылке (расшифровка в документации*) | КОНТЕКСТ |

---

## Связи
- household_key: transaction_data, campaign_table, coupon_redempt, hh_demographic
- product_id: transaction_data, product, coupon, causal_data
- campaign: campaign_desc, campaign_table, coupon, coupon_redempt

## Особенности и риски
- Тип A: купоны подобраны по прошлому поведению (16 из пула), какие именно получила семья, в данных не видно.
- Типы B и C: все участники получают все купоны кампании.
- Затрат на кампании в данных нет.
- Не все семьи получали кампании.
